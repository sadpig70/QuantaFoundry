# Verification Paths — the independent checks and what each covers

> **Purpose** (QF-0711 U8): make the "independent verification paths" claim *auditable* — name every
> path, what fragment it covers, its command, and its honest boundary. Live per-path coverage counts +
> the app×path matrix are authoritative in
> [`registry/VERIFICATION-COVERAGE.json`](../registry/VERIFICATION-COVERAGE.json)
> (regenerated by `python -m qf_witness.registry.coverage_matrix`).
>
> **Honest framing**: coverage sets are **complementary, not universal** — each path verifies a
> *fragment* (permutation / diagonal-phase / Clifford / tensor-network / …). Most assets are covered by
> their **primary seal** (dense C4 / Clifford tableau / ZX) plus zero-or-more of these supplementary
> paths. Assets with **no supplementary path** (`primary_seal_only` in the coverage JSON) rely on the
> single dense oracle — that list is the data for the next verification investment.

## Primary seal paths (the baseline every sealed asset passes)

| Path | Covers | Command | Boundary |
|---|---|---|---|
| **dense C4** (`second_oracle`) | all sealed modules, small dense apps | `python -m qf_witness.verify.second_oracle` | independent numpy re-derivation; shares endian/phase/atol conventions |
| **Clifford tableau** (Tier-2) | large Clifford circuits (QEC encoders, transversal) | in-seal | stabilizer tableau, dense not materialized |
| **ZX** (Tier-3) | Clifford+T method identities | `python -m qf_witness.verify.zx_verify` | conservative (safe false-negative); method-level, not a per-app census |

## Supplementary independent paths (per-app census — `.pgf/proofs/*` sidecars)

| Path | Covers (fragment) | Command | Boundary |
|---|---|---|---|
| `column` | Shor full unitary, column-by-column (H·iQFT) | `python -m qf_witness.verify.column_verify` | float-atol; n≤18 |
| `ring` | iQFT factor in ℤ[ζ₂₅₆], integer-exact | `python -m qf_witness.verify.ring_column_verify` | iQFT factor only (float 0); modexp/H-wall separate |
| `subspace` | modexp core basis permutation | `python -m qf_witness.verify.perm_subspace_verify` | computational-basis only, not full unitary |
| `cuc` | n≥19 Shor: exhaustive modexp + ring iQFT, composed | `python -m qf_witness.verify.cuc_verify` | composition argument, not whole-column dense |
| `anf` | Boolean/bit-vector (permutation) normal form | `python -m qf_witness.verify.anf_verify` | permutation fragment (diagonal phase blind) |
| `groebner` | ℤ[ω] phase-ideal (diagonal/monomial) | `python -m qf_witness.verify.groebner_verify` | diagonal-phase fragment (complementary to anf) |
| `pathsum` | ℤ[ω₈] path-sum | `python -m qf_witness.verify.pathsum_verify` | small n; path-count bounded |
| `stabrank` | stabilizer-rank | `python -m qf_witness.verify.stabrank_verify` | ry/z5/ω₈ gate set; large T-count skipped (recorded) |
| `matchgate` | matchgate SO(2n) / Majorana | `python -m qf_witness.verify.matchgate_verify` | matchgate-representable only |
| `tncontract` | tensor-network contraction | `python -m qf_witness.verify.tncontract_verify` | bond-dimension bounded |
| `qmdd` | decision-diagram (QMDD) | `python -m qf_witness.verify.qmdd_verify` | DD-representable fragment |
| `affine` | rs73 pure-CNOT GF(2) affine map, full unitary | `python -m qf_witness.verify.rs73_affine_verify` | pure-CNOT (linear) circuits only |
| `compositional` | app assembly re-composed from first-principles module unitaries (no app_assemble/qualtran) | `python -m qf_witness.verify.compositional_verify` | dense-feasible apps (cost≤budget, n≤13; sub-app steps recursively inlined); shares the dense formalism — an app-level extension, **not** a new independent formalism |

## Coverage summary

Live counts + the full `app → [paths]` matrix, the `coverage_histogram` (how many assets are covered by
1 / 2 / 3+ paths), and `primary_seal_only` (assets with no supplementary path) are in
[`registry/VERIFICATION-COVERAGE.json`](../registry/VERIFICATION-COVERAGE.json). Regenerate with
`python -m qf_witness.registry.coverage_matrix` (auto-generated at the end of every `reproduce_all`,
after the per-path verifiers settle); `--check` verifies it is fresh (standalone/CI drift gate).

The README headline "independent verification paths" count refers to these supplementary census paths
(plus the primary seal paths above). This document + the coverage JSON are the authoritative list —
prefer them over any bare number elsewhere.
